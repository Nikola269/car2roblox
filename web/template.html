Parts to keep

Many mods ship without wheels, with a wheel left in the middle of the car, or with only some of them. Wheels are moved, copied or generated so all four sit on their hubs. If a mod's own wheels still look wrong, tick "Always use new tires". Turn "Add tires" off if the body already has its wheels built in.

Roblox limits

Meshes over the triangle limit are split into several parts without losing detail. A whole-car budget simplifies the model instead.

Studio car

Rigs each wheel with its own spring-loaded suspension upright (and a steering knuckle on the front wheels) instead of a fixed hinge, and drives it with a simulated engine - RPM, a torque curve and gears - in the spirit of the community "A-Chassis" rigs. Leave this off for the simpler, lighter fixed-hinge rig.

    Checks part, material and texture names and the files in mod archives. It cannot see what a picture shows.
    Put it in Roblox Studio
    1. Unzip the download. It also holds preview.png, a picture of the converted car for the Roblox upload page.
    2. In Studio choose File > Import and pick the .glb. Set Scale Unit to Studs and tick Import Only As Model.
    3. Select the imported Model, open View > Command Bar, paste the setup script and press Enter.
    4. Press Play and sit in the car. W/S drives, A/D steers.

    The setup script has been run against a stand-in for the Roblox API, not in Studio itself. Use Drive above to check size, wheels and steering first; it is a quick preview, not Roblox physics.
